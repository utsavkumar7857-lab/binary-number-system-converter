Binary — Base 2

The binary number system uses only two digits, 0 and 1. It is widely used in digital electronics and computer systems.

Decimal — Base 10

The decimal number system uses ten digits, from 0 to 9. It is commonly used in everyday calculations.

Octal — Base 8

The octal number system uses digits from 0 to 7. Each octal digit represents three binary bits.

Hexadecimal — Base 16

The hexadecimal system uses digits 0 to 9 and letters A to F. Each hexadecimal digit represents four binary bits.
